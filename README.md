# Fish Speech S2-Pro Portable для Windows

**Built with Fish Audio.** Неофициальная переносимая обёртка для [Fish Speech](https://github.com/fishaudio/fish-speech) и модели [S2-Pro](https://huggingface.co/fishaudio/s2-pro).

**Скачайте ZIP из [Releases](https://github.com/BegemotX99/fish-speech-s2-portable-windows/releases/latest), распакуйте и запустите `1_INSTALL_AND_RUN.bat`.** Подробная инструкция на русском находится в `MANUAL_RU.html` внутри ZIP.

Это один ZIP с установщиком, интерфейсом и инструкцией. **Python, пакеты, FFmpeg и веса модели загружаются при первом запуске на целевом компьютере.** После успешной подготовки папку можно целиком перенести на другой совместимый ПК и запускать через `2_RUN.bat` без интернета.

## Требования и ограничения

- Windows 10/11 **x64**, PowerShell 5.1+, доступ к интернету при первой подготовке.
- NVIDIA с актуальным драйвером. Выбран PyTorch **2.8.0 + CUDA 12.8**, поддерживающий поколение RTX 50. Системный CUDA Toolkit, Python, Git, Conda и FFmpeg устанавливать не нужно.
- Для RTX 5080 с 16 ГБ VRAM выбран контекст **4096**, BF16 для текстовой модели, один запрос одновременно, короткие независимые фрагменты. `torch.compile` отключён. Кодек работает в штатной FP32 с autocast во время инференса.
- Документация upstream указывает **24 ГБ VRAM** для S2-Pro и Linux/WSL как целевые системы. Эта обёртка запускает обычный PyTorch непосредственно в Windows. **Нативный запуск на RTX 5080 не проверен на GPU в среде сборки и не гарантирован.** Уменьшенный контекст снижает расход памяти, но не является измерением фактического пика VRAM.
- Рекомендуется **32 ГБ RAM**, предпочтительно 64 ГБ при других тяжёлых программах. Оставьте **35–40 ГБ** свободного места для весов, распаковки, пакетов и кэша. Установщик проверяет минимум 30 ГБ перед первой загрузкой.

Строка `CUDA UMD Version: 13.4` относится к драйверу. Она не означает, что нужно искать PyTorch именно с CUDA 13.4: выбранная сборка приносит свои библиотеки CUDA 12.8. Проверьте работу CUDA через `3_DIAGNOSTICS.bat`.

## Первый запуск

1. Скачайте `FishSpeech-S2-Portable-Windows-v1.0.0.zip` из Releases. Обычный GitHub `Source code (zip)` также содержит исходники установщика, но пользовательский ZIP удобнее.
2. Полностью распакуйте архив, например в `D:\AI\FishSpeech-S2-Portable`. Короткий путь уменьшает риск ограничений длины путей Windows. Пробелы поддерживаются. Не запускайте батник из окна архиватора, `Program Files` или папки только для чтения.
3. Откройте `MANUAL_RU.html` обычным браузером. Затем дважды нажмите `1_INSTALL_AND_RUN.bat`. Права администратора не нужны.
4. Дождитесь скачивания и проверки файлов. Веса — примерно 11 ГБ; PyTorch скачивает ещё около 3.2 ГиБ, остальные компоненты добавляют трафик. Не запускайте одновременно второй установщик в этой папке.
5. Откроется `http://127.0.0.1:7860`. Подождите сообщения «Модель загружена». Если браузер не открылся, введите адрес вручную.
6. Введите короткий текст и нажмите «Создать аудио». WAV и исходный текст сохраняются в `output`.

При обрыве интернета снова запустите первый батник. Загрузчик весов продолжает файлы `.part`, проверяет размеры и SHA-256. Загрузка повреждённого файла начинается заново. Другие скачивания повторяются автоматически; сервер может не поддержать возобновление, тогда файл загружается заново.

## Обычная работа

| Файл | Назначение |
|---|---|
| `1_INSTALL_AND_RUN.bat` | Подготовить компоненты, докачать отсутствующие файлы модели и запустить интерфейс |
| `2_RUN.bat` | Запустить уже подготовленную копию без установки и сетевых загрузок |
| `3_DIAGNOSTICS.bat` | Проверить импорты, FFmpeg, GPU, версию CUDA и реальную BF16-операцию на видеокарте |
| `4_VERIFY_MODEL.bat` | Повторно проверить SHA-256 всех весов и восстановить повреждённые файлы; для восстановления нужен интернет |
| `settings.json` | Порт, контекст и устройство |
| `MANUAL_RU.html` | Полная инструкция в браузере |

Остановить сервер: **Ctrl+C в консоли**, при запросе остановки пакетного файла ответьте `Y`, либо закройте окно консоли. Закрытие вкладки браузера само по себе не выгружает модель.

Для озвучки своим голосом выберите чистый аудиообразец **5–15 секунд**, добавьте его **точную расшифровку**. Файл должен быть до 20 МБ. FFmpeg приводит образец к моно WAV 44.1 кГц; используются первые 20 секунд. Расшифровка должна соответствовать этому фрагменту. Образец можно хранить в `voices` и выбирать через интерфейс. Интерфейс не копирует исходный образец туда автоматически.

Без образца модель выбирает голос сама; при разделении длинного текста тембр может меняться. Для стабильности используйте один и тот же образец. Эта компактная UI-обёртка поддерживает **одного диктора на задание**. Многоголосные теги `<|speaker:N|>` в ней отклоняются. Полные возможности upstream доступны в скачанных исходниках `app`.

Можно использовать указания вида `[whisper]`, `[excited]`, `[pause]`. Они влияют на модель вероятностно. Длинный текст делится примерно по 220 символов, между фрагментами добавляется 120 мс тишины. Ограничение — 10 000 символов на задание; контекст между фрагментами не переносится. Фрагмент ограничен 1024 новыми аудиотокенами, поэтому чрезмерно длинная/медленная речь может обрезаться: делите её на более короткие предложения.

## Где находятся файлы

```text
FishSpeech-S2-Portable/
  1_INSTALL_AND_RUN.bat
  2_RUN.bat
  3_DIAGNOSTICS.bat
  4_VERIFY_MODEL.bat
  settings.json
  portable/             установщик, загрузчик, локальный интерфейс
  runtime/              отдельный Python, uv, FFmpeg, локальные VC++ DLL
  app/                  закреплённые исходники Fish Speech
  checkpoints/s2-pro/   веса, токенизатор, лицензия модели
  cache/                кэш загрузок, uv, PyTorch, CUDA, Hugging Face и др.
  temp/                 временные файлы и промежуточная распаковка
  logs/                 установка, диагностика и сообщения инференса
  voices/               ваши образцы, если вы сами положите их сюда
  output/               готовые WAV и исходный текст
```

`TEMP`, `TMP`, кэши Python-библиотек и CUDA задаются внутри процесса и направляются в эту папку. Параметры системы, реестр и постоянный `PATH` не меняются; venv с абсолютными путями не используется. FFmpeg вызывается по локальному пути. Microsoft VC++ Runtime **извлекается**, его установщик/MSI **не запускается**, DLL остаются рядом с portable Python.

Переносимость не отменяет работу Windows: драйвер NVIDIA остаётся системным; Windows может писать журналы, файл подкачки и Prefetch, антивирус и браузер используют свои служебные файлы. История/кэш браузера не перенаправляются этой обёрткой. Поэтому абсолютное обещание «ни одного байта за пределами папки» технически неверно. Файлы самой сборки и управляемые ею временные каталоги хранятся локально.

## Перенос на другой ПК и работа без сети

1. Успешно выполните первый запуск и закройте сервер.
2. Скопируйте **всю папку**, включая `runtime`, `app`, `checkpoints`, `portable` и файлы-маркеры с именами, начинающимися с точки.
3. На другом Windows x64 ПК с совместимым драйвером NVIDIA запустите `2_RUN.bat`. Буква диска и путь могут измениться.
4. Для проверки целостности весов запустите четвёртый батник. При целых весах сеть ему не нужна.

После подготовки папку можно самостоятельно упаковать в большой ZIP — получится полностью заполненный переносимый набор. Исходный небольшой релизный ZIP является установщиком и **не является заранее заполненным офлайн-дистрибутивом**.

## Очистка

Сначала остановите сервер. Можно удалить содержимое `temp` и `cache`; это не удаляет веса из `checkpoints`. Повторная установка пакетов после очистки кэша может потребовать интернет. Временные WAV загруженных образцов автоматически удаляются после задания. Готовые аудио и текст удаляйте из `output` вручную. `logs` может содержать текст для озвучки — не публикуйте его без проверки. Веса, runtime и исходники для обычной очистки удалять не нужно.

## Если что-то не работает

| Симптом | Действие |
|---|---|
| `CUDA out of memory` | Закройте игры, редакторы и другие модели. Оставьте `context: 4096`, укоротите образец до 5–10 с и текст. Перезапустите сервер. Если 16 ГБ всё равно недостаточно, используйте GPU с большим объёмом VRAM либо CPU; обещания работы на 16 ГБ нет. |
| `CUDA NOT AVAILABLE` | Запустите диагностику. Установите подходящий драйвер NVIDIA с сайта производителя, перезагрузите ПК. Скрипт не меняет драйвер. |
| `no kernel image` | Убедитесь, что используется вложенный PyTorch `2.8.0+cu128`, а не системный Python. Запускайте только батники. Приложите вывод диагностики. |
| `WinError 126/127`, отсутствует DLL | Первый батник извлекает VC++ DLL локально. Для повторного извлечения удалите только `runtime\cpython-3.12.12-windows-x86_64-none\.vc-runtime-ready` и снова запустите первый батник. Если Windows поместила файл в карантин, проверьте конкретное предупреждение; не отключайте защиту целиком. |
| `The paging file is too small` / ошибка 1455 | Закройте другие модели и приложения, освободите RAM и перезапустите. Обёртка уже исключает лишнюю FP32-копию текстовой модели при загрузке, но для весов, кодека и Windows всё равно нужна память. Скрипт не меняет настройки файла подкачки. |
| Ошибка скачивания/403/429/SSL | Проверьте доступ к GitHub, PyPI, download.pytorch.org, Hugging Face и CDN. Повторите позже. Проверка TLS не отключается. В корпоративной сети может потребоваться настройка сертификатов администратором сети. |
| `SHA-256 mismatch` | Загрузчик повторит скачивание. При повторении приложите лог, не подменяйте ожидаемый хеш случайным значением. |
| `app exists without its version marker` | Остановите сервер, переименуйте `app` в `app-backup` и повторите первый запуск. Ваши файлы останутся в резервной папке. |
| Порт занят / `WinError 10048` | Закройте другой экземпляр. Либо измените `port` в `settings.json`, например на `7861`, и снова запустите. |
| Браузер пишет «Сервер недоступен» | Проверьте консоль. Первый запуск может долго загружать модель в RAM/VRAM. Откройте адрес с портом из `settings.json`. |
| Озвучка обрывается или голос меняется | Укоротите предложения, используйте один качественный образец и точную расшифровку. Слишком длинные фрагменты могут достигать лимита токенов. |
| Не удаётся записать файл / длинный путь | Распакуйте в короткую доступную папку, например `D:\AI\FishS2`. Не используйте ZIP как виртуальную папку. |

`settings.json` по умолчанию:

```json
{"port": 7860, "context": 4096, "device": "cuda"}
```

`context: 8192` увеличивает потребление памяти и для RTX 5080 16 ГБ не рекомендуется. `device: "cpu"` включает медленный CPU-режим, которому нужно достаточно RAM; это запасной способ, скорость GPU он не обеспечивает. Контекст 2048 не поддерживается этой сборкой: upstream резервирует 2048 токенов для генерации.

## Что сделано и закреплено

- Fish Speech commit `0f8a12e8a651062fdee9c33a894bdccd3a8513f1`.
- Модель `fishaudio/s2-pro`, revision `1de9996b6be38b745688de084d87a5633f714e4e`.
- CPython 3.12.12 через uv 0.13.8 без регистрации Python в Windows.
- PyTorch/Torchaudio 2.8.0+cu128; полный набор пакетов и хешей в `requirements.lock`.
- FFmpeg 9.0.2 Essentials от Gyan, скачивается из зеркала автора на GitHub.
- Microsoft VC++ Runtime x64 из закреплённого официального пакета Microsoft; локальное извлечение 12 DLL.
- Исправлен конфликт свежего TensorBoard с ограничением protobuf из upstream: закреплён TensorBoard 2.19.0 и protobuf < 6.
- Исходники и веса Fish Speech не меняются. Контекст ограничивается обёрткой **в памяти**, временной подменой загрузчика конфигурации.
- Конструктор текстовой модели вызывается на устройстве `meta`; штатный загрузчик затем присваивает реальные веса checkpoint. Три служебных буфера создаются отдельно. Это убирает лишнюю случайно инициализированную FP32-копию модели при загрузке и уменьшает пик RAM. Исходные файлы при этом не патчатся.
- Собственный русский интерфейс без Node.js, Gradio и внешних скриптов. Слушает только `127.0.0.1`, задания выполняются последовательно. Для POST используется случайный токен текущего запуска.
- Загрузки uv, исходников, FFmpeg, VC++ и всех файлов модели проверяются SHA-256; пакеты закреплены хешами. Установка зависимостей не обновляет их автоматически до новых версий.

Результаты проверок и их ограничения описаны в `VALIDATION.md`. Сборка не позиционируется как официальный релиз Fish Audio.
