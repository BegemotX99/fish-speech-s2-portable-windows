# Проверки сборки 1.0.0

Проверено 16 ноября 2026 года в Windows x64. GPU NVIDIA в среде сборки недоступен: `torch.cuda.is_available()` возвращает `False`. Поэтому ниже отдельно перечислены выполненные проверки и ограничения.

## Выполнено

- Скачан отдельный CPython 3.12.12 с помощью uv 0.13.8, без регистрации в Windows и без глобального Python.
- Разрешены и установлены 128 пакетов из `requirements.lock`, включая `torch==2.8.0+cu128` и `torchaudio==2.8.0+cu128`. Установка с `--require-hashes` прошла успешно.
- Обнаруженный конфликт свежего TensorBoard с protobuf устранён закреплением TensorBoard 2.19.0. Импорты текстовой модели, кодека, inference engine и схем запросов проходят.
- Проверено наличие `sm_120` в скомпилированных архитектурах установленного CUDA wheel: `sm_61 sm_70 sm_75 sm_80 sm_86 sm_90 sm_100 sm_120`.
- FFmpeg 9.0.2 запускается из локальной папки. Его ZIP проверен по опубликованной автором SHA-256.
- Из официального пакета Microsoft извлечены 12 x64 DLL Visual C++ Runtime. Установщик EXE/MSI не запускался. SHA-256 пакета проверен, DLL и лицензия остаются рядом с Python.
- Реально скачаны все 11 выбранных файлов S2-Pro с закреплённой revision, размеры и SHA-256 каждого подтверждены. Установочный релизный ZIP их не содержит: загрузка выполняется на целевом ПК.
- Загрузчик проверен на локальном HTTP-сервере: разрыв после 5 000 000 байт, возобновление через `Range` с этой позиции, проверка SHA-256, повторное использование целого файла без сети и перезагрузка повреждённого полного `.part`.
- Windows PowerShell 5.1 успешно выполнил `bootstrap.ps1 -Mode Install` с реальными компонентами. Проверены синтаксис PowerShell, все Python-файлы и JavaScript интерфейса (`node --check`).
- **Реальный CPU-синтез** короткой фразы через S2-Pro и DAC завершился. Текстовая модель загрузилась с сообщением `All keys matched successfully`. Получен конечный WAV: 44 100 Гц, 22 528 отсчётов, примерно 0.511 секунды; массив не пустой, содержит конечные значения.
- После оптимизации загрузки на `meta` повторён CPU-синтез. Он завершился успешно. Также проверен путь **аудиообразец → FFmpeg → моно WAV → reference encoder → S2-Pro → DAC → сохранённый WAV и TXT → завершённое задание**. Для технической проверки использован повтор короткого тестового синтезированного аудио, а не запись реального человека.
- HTTP-проверка локальной UI: отдаётся русский HTML, токен текущего запуска подставляется в страницу, `/health` работает, обращения к путям вне `output` отклоняются, POST без токена получает 403.
- **Переносимость:** вся заполненная папка была перемещена в другой путь с пробелами и кириллицей. Там прошли повторная подготовка с `UV_OFFLINE=1` без скачиваний, импорты Fish Speech, запуск FFmpeg и загрузка локального токенизатора. Затем папка возвращена назад. Удалён неиспользуемый абсолютный junction, который uv создаёт для alias Python; батники используют точный локальный путь интерпретатора.

## Что не подтверждено

- Не выполнялся GPU-синтез на RTX 5080 или другой NVIDIA GPU, не измерялся пик VRAM, скорость и длительная устойчивость GPU-режима. Операция BF16 на GPU проверяется `3_DIAGNOSTICS.bat` уже на целевом компьютере.
- Upstream заявляет 24 ГБ VRAM и ориентируется на Linux/WSL. Контекст 4096 уменьшает расход памяти, но не является гарантией работы на RTX 5080 с 16 ГБ.
- Короткие CPU-тесты подтверждают прохождение вычислительного пути и сохранение файла. Они не являются оценкой качества русского произношения, сходства голоса или многоминутной озвучки.
- Сеть при первом запуске зависит от доступности GitHub, PyPI, PyTorch CDN, Microsoft и Hugging Face/CDN. Отдельная чистая виртуальная Windows без каких-либо установленных библиотек не использовалась.
- HTTP и синтаксис UI проверены программно. Полная визуальная проверка в подключённом браузере не выполнена: браузер среды проверки не смог подключиться к loopback-порту тестового процесса.
- Не выполнялся аудит файловых обращений всех компонентов ОС. Кэши и временные файлы приложения перенаправлены локально, но системные файлы Windows, драйвера, антивируса и браузера находятся под их управлением.

При проблеме приложите текст из `logs` и вывод `3_DIAGNOSTICS.bat`, предварительно удалив личные тексты и пути, которыми не хотите делиться.
